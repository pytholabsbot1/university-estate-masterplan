# University Estate master plan

Concept master plan for a gated plotted township with a 25-acre university, Jot Sadruddin + Jot Dariya, Tehsil Pahari, District Deeg, Rajasthan. Site 28.40 ha, traced from BhuNaksha.

- `generator/` — `layout.js` builds the layout and areas; `master2.html` draws it; `render.sh` exports PNG/PDF with headless Chrome; `run.js` prints the land-use numbers.
- `survey/` — parcel tracing scripts, outline, plot records and the map-vs-record check.
- `output/` — v3 plan: 51.0% plots, 294 plots plus 23 shop lots.
- `legacy/` — v2 plan and exports.

Concept stage only. Verify against the Rajasthan township rules, a DGPS survey and a patwari demarcation before approval.
